<h1>SP-Mailbox</h1>

<p>해당 프로젝트는 서버 간에 공유되는 우편함(선물함)을 SP-Framework의 DB/프록시로 구현한 플러그인 입니다</p>
<p>해당 프로젝트는 미완성된 프로젝트 입니다 일부 오류가 있을 수 있습니다</p>
<p>해당 프로젝트는 SP-Framework(DB, 프록시)가 반드시 필요합니다</p>

<h2>플러그인 버전</h2>

- 플러그인 : spigot 1.12+
